# URL → Markdown 변환과 내보내기

## Decisions

- 본문 추출과 Markdown 변환은 `defuddle` 라이브러리(`markdown: true`)로 서버에서 합니다. 호스팅 API(`defuddle.md/<url>`)는 쓰지 않습니다.
- 페이지 HTML은 서버가 가져옵니다. 로그인이 필요한 페이지, JavaScript로만 본문을 그리는 페이지, HTML이 아닌 응답(PDF, 이미지)은 변환하지 않고 오류로 안내합니다.
- ChatGPT·Claude로 열 때 URL 인코딩 후 길이가 8,000자 이하면 `?q=`에 담고, 넘으면 전체 텍스트를 클립보드에 복사한 뒤 `?q=` 없이 새 대화를 열면서 붙여넣기 안내 토스트를 보여줍니다. 본문을 자르지 않습니다.
- 프롬프트는 ChatGPT·Claude로 열 때만 본문 앞에 붙입니다. 복사와 `.md` 다운로드 결과물은 프롬프트 없는 원문 문서입니다.
- 직접 입력한 프롬프트는 저장하지 않는 1회용입니다.
- 이 서비스에서는 요청 제한, SSRF 방어 같은 보안 하드닝을 하지 않습니다.

## Why

`defuddle`은 사용자가 필수로 지정했고, 호스팅 API는 유료 키가 필요합니다. `defuddle/node`는 ESM 전용이라 서버 쪽 사용 환경이 ESM import를 지원해야 합니다.

`?q=`에는 길이 한도가 있습니다. 본문을 자르면 LLM이 글 일부만 보고, 항상 복사만 하면 짧은 글에서도 붙여넣기가 필요해서, 사용자가 클립보드 폴백을 골랐습니다. 복사·다운로드는 다른 용도로도 쓰이므로 프롬프트를 섞지 않습니다.

강의용 학습 템플릿이라 스펙이 요구하지 않은 하드닝은 범위 밖입니다.

## Boundaries

- 8,000자 한도는 실측이 아니라 가정입니다. 한글은 인코딩하면 글자당 9자가 되어 약 1,700자만 넘어도 폴백이 동작합니다. ChatGPT·Claude가 더 긴 `?q=`를 받는다고 확인되면 올려도 됩니다.
- `https://chatgpt.com/?q=`와 `https://claude.ai/new?q=`가 입력란을 미리 채워 준다는 것도 로그인 상태에서는 확인하지 못한 가정입니다.

## Reconsider when

- `defuddle`이 Node 라이브러리 형태 지원을 중단하거나 사용 방식이 바뀔 때
- ChatGPT·Claude가 `?q=` 동작을 바꾸거나 없앨 때. 그때는 짧은 글도 폴백과 같은 클립보드 방식으로 통일합니다.
- 일부 사이트가 서버발 요청을 봇으로 막아 오류가 반복될 때(헤드리스 브라우저는 현재 범위 밖입니다)

## Still-rejected alternatives

- 긴 본문을 잘라서 `?q=`에 싣는 방식 — LLM이 글 일부만 봅니다.
- 항상 클립보드로만 넘기는 방식 — 짧은 글에서도 붙여넣기가 필요합니다.
- defuddle 호스팅 API — 유료 키가 필요하고 라이브러리 사용이 지정되어 있습니다.
